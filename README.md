# BOBBO · 布卜布卜

每一餐，都值得被看见。

BOBBO 是一个围绕猫咪吃饭场景开发的摄像头项目。你可以通过微信小程序看猫、查回放，了解猫咪什么时候吃过饭，也可以把一天里的可爱镜头整理成带音乐的吃播视频。

这里公开了小程序、服务器程序和相关算法代码，方便大家了解、使用和继续改进。

## 能用它做什么？

### 看看猫咪现在在干什么

在“实时”页查看摄像头画面，或选择日期查看过去的录像。移动警报列表用于回看画面发生变化的时间，家庭成员也可以通过设备共享一起查看。

### 不用翻整天录像，也能找到吃饭片段

系统会从录像里寻找猫咪，并进一步判断它是否在碗边进食。分析完成后，整理出进食时间、时长和餐次，在“今日”页查看汇总。

回放时间条用不同颜色区分普通录像、有猫的区间和进食区间，帮助你找到想看的位置。

这里的进食时长是根据画面估算的，不是吃掉了多少克猫粮；多只猫共用一个摄像头时，也不能直接把设备统计当成每只猫的独立记录。

### 在开始吃饭时收到提醒

项目包含开始进食的确认和提醒功能：不是画面一动就通知，而是先观察是否有持续进食的迹象，再决定是否提醒。

即时提醒与历史补查需要分开处理。补查昨天的录像，不应该被当成“猫咪现在开始吃饭”；接入时需要检查这部分设置和实际表现。

### 留下每一顿，也留下一天的可爱瞬间

“吃播”页可以按日期查看每顿进食片段，并查看当天的精选视频。

精选不是简单截取视频开头。它会从当天多顿素材里，寻找猫脸清楚、离镜头较近、朝向合适的镜头，保留前后连贯的动作，再剪成一个带背景音乐的视频。可以设置成片时长偏好，也有下载保存入口。

素材少时，成片可以更短，不会为了凑时长反复播放同一个镜头。生成和下载功能需要部署者准备好模型、音乐和视频存储。

## 它是怎么做到的？

可以把它理解为两件事：

- **记录吃饭**：先找猫，再结合饭盆位置、猫脸和动作判断进食，最后整理成一顿顿记录。
- **制作吃播**：从进食素材中挑好看的镜头，保留连贯动作，把一天的片段剪到一起并配乐。

想了解为什么这样判断、如何选镜头，以及代码在哪里，读 [进食识别与吃播是怎么做的](docs/ALGORITHMS.md)。这份介绍先讲原理，不要求你先懂代码。

## 使用前需要知道

这是一套源码，不是下载后就能直接连接任意摄像头的成品服务。运行它，需要自己的服务器、微信小程序账号、兼容摄像头，以及厂商提供的接入工具。

仓库没有放入账号密钥、用户录像、第三方模型文件和音乐。需要哪些文件、怎么配置，都放在安装指南中说明。

识别也有局限：遮挡、光线、镜头方向和饭盆位置都会影响判断。有猫不等于在吃饭，进食记录也不能替代健康诊断。自动测试通过不代表所有摄像头和家庭场景都已经验证。

## 代码与授权

主要代码分别放在：

- `miniprogram/`：你在微信里看到的页面和操作。
- `server/`：管理设备、整理记录、发送通知和制作视频。
- `vision/`：从画面里找猫、判断行为、挑选吃播镜头，以及人工标记视频的工具。
- `vision-v32/`：保留的 V3.2 进食分析版本，方便对照和复现。
