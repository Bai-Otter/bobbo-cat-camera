# 猫饭日记 - 前端整合说明

给负责整合的 AI / 开发者看的说明。这套前端在你**已经跑通 SDK 的 UniApp 项目**基础上替换/新增，保持原有 SDK 调用逻辑不变。

## 一、这次交付了什么

三个新的 tab 页面（米色奶油高端风，复刻 UI 设计图）：

| 文件 | 作用 | 状态 |
|------|------|------|
| `pages/today/index.vue` | 「今日」首页 | 设备在线/电量接真实 SDK，进食时间线和精选用假数据 |
| `pages/clips/index.vue` | 「片段」页（看回放入口）| 片段网格假数据，「录像回放」按钮接真实 SD 卡回放 |
| `pages/profile/index.vue` | 「我的」页 | 配网入口在这，接真实 addDevice |
| `pages.json` | 改成三 tab 布局 | 替换原文件 |

原有页面**保持不动**，直接复用：
- `pages/live/index.vue`（实时视频）
- `pages/live/replay.vue`（SD 卡回放）
- `pages/bind/addDevice.vue`（配网）
- `pages/login/index.vue`（登录）

## 二、整合步骤

1. 把 `pages/today/`、`pages/clips/`、`pages/profile/` 三个文件夹放进项目 `pages/` 下
2. 用新的 `pages.json` 替换原来的（注意：把首页从 `pages/index/index` 改成了 `pages/today/index`）
3. 原来的 `pages/index/index.vue`（设备列表）可以保留作为备用，或删掉
4. 放入 `static/images/` 下的占位图（见下）
5. tabBar 图标需要准备 6 张 PNG（见第四节）

## 三、真实 SDK 对接点（已写好，无需改动）

所有页面都复用你 `main.js` 里初始化的 `this.JLWXSDK`，调用方式和你现有 index 页完全一致：

```javascript
// 今日页 / 片段页 / 我的页 都用这个链路拿真实设备
this.JLWXSDK.getDeviceList({ page: 1, limit: 1 }, ...)
  → this.JLWXSDK.getDeviceToken({ sns: [...] }, ...)
  → this.JLWXSDK.getNewDeviceStatus({ token: [...] }, ...)
```

跳转实时视频（复用现有 live 页，传参格式一致）：
```javascript
uni.navigateTo({ url: '/pages/live/index?device=' + encodeURIComponent(JSON.stringify(this.device)) })
```

跳转 SD 卡回放（复用现有 replay 页）：
```javascript
uni.navigateTo({ url: '/pages/live/replay?device=' + encodeURIComponent(JSON.stringify(this.device)) })
```

配网（复用现有 addDevice 页）：
```javascript
uni.navigateTo({ url: '/pages/bind/addDevice' })
```

## 六、假数据位置（后续接真实数据时改这里）

| 页面 | 假数据变量 | 接什么真实数据 |
|------|-----------|---------------|
| today | `meals[]` | AI 进食检测结果 |
| today | `featured` | AI 自动剪辑的精选片段 |
| today | `todayEatCount` | 当日进食次数统计 |
| clips | `clips[]` | 设备 SD 卡片段 / AI 剪辑 |
| clips | `dateChips[]` | 真实日期 + 当日片段数 |
| profile | `joinDays` | 用户注册时长 |

进食时间线和片段是产品的 AI 亮点功能，前端结构已搭好，等后端 AI 管线就绪后把假数据换成接口返回即可，UI 不用动。
