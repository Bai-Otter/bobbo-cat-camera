# 剧情分类 → 按标签配乐（story-music-mood-v1）

用户已认可现有12首BGM。本次在原算法上补充剧情类别识别与本地匹配，不换曲库、不重做声音、不增加看图轮次。

## 标识体系

每首可以有多个标签。产品策划适配分：3=优先，2=兼容，1=弱相关不进入匹配，0=不匹配。网页深色显示优先标签，浅色显示兼容标签。这些是产品审美标注，不是作者官方标签，不代表猫真实心理；可按用户反馈继续修改。

## 一轮API怎么实现

`vision.build_prompts`仅在`story_enabled=true`且`story_mode=inner_monologue`时追加`prompts/story-music-mood-v1.txt`。吃播-only与旧原声互动Prompt不变。先按原标准选片与组织独白，再只为**最终保留的小剧场**分类，不按整条未剪视频的主调分类，也不为了音乐改动镜头。

原JSON的`interaction_story`内部额外返回：

```json
{
  "music_mood": {
    "category": "warm",
    "confidence": 0.85,
    "reason": "人贴近猫头轻抚，小猫留在人手旁",
    "evidence_frame_ids": ["F0002", "F0003"]
  }
}
```

这只是格式示例，不是本次实际AI识别记录。类别限定为：

- warm：温馨亲昵，亲亲/贴脸/依偎/轻抚为主体，不能见到人就判温馨。
- funny：呆萌搞笑，有笨拙/扑空/愣住/小反差，普通吃饭不硬编笑点。
- sneaky：好奇试探，探头/观察/试探/惦记贯穿剧情，不把“偷偷摸摸”当真实心理诊断。
- proud：小小得意，尝试→达到小目标→满足的转变，不凭一句“本咪”决定。
- relaxed：轻松日常，自然喂食/陪伴，没有突出戏剧转折；正常类别。
- uncertain：证据不足或难分主导类别，转入轻松日常兜底。

模型不收曲目文件路径，不选择歌名、不控制音量。只多返回一小段分类信息，没有新增视觉/TTS请求，没有第二轮图像审查。

## 校验、匹配与历史兼容

1. 原片段、互动链、独白先通过原有验证。
2. 分类必须有合法类别、0–1有限自评置信度、1–160字具体理由、1–6个不重复的帧ID。所有证据必须属于小剧场已批准同镜覆盖帧，不能引用片外。
3. 对齐实际源帧剪点后再确认分类证据仍在成片内；若证据落在被收掉的边缘，明确降级，不扩剪点或另看图片。
4. 缺失/非法/低于0.6/uncertain不令视频生成失败。保存真实状态和兜底原因，以relaxed选择音乐；自评置信度不是经校准的正确率。
5. 启用曲目中寻找对应类别最高适配分（至少2）的候选，候选内等概率随机。可能连续重复，不承诺轮播。
6. 该类别无可用曲目时，BGM阶段明确失败并保留配音无BGM成片，不能偷偷改配另一种情绪。
7. 混音前保存任务级`story-music-selection.json`：实际曲目、标签快照/版本、分类、理由、候选ID、匹配分。重试复用原选择，即使后来改了标签或类别，也不改该任务历史。
8. 历史`random_per_job`选曲记录继续按原曲播放，不伪标成“AI剧情匹配”。新建恢复任务从历史响应取分类；历史没有分类时明确日常兜底，不补发视觉请求。

原有约-28dBFS音乐基准、说话时35%音乐音量、淡入淡出、原声、授权克隆音色、额头字幕和视频码流保持不变。

## 配置与显示

已有服务专属`story-profile.json`保留原字段，并补充：

```json
{
  "music_selection_policy": "story_mood_v1"
}
```

必须同时配置上一版`music_library_file`。没有新字段的部署保持旧全库随机；没有曲库的部署保持旧固定BGM，避免升级时静默改变其他实例。

- 曲库页：每首显示标签；`/api/music`的`mode=story_mood_per_job`代表服务加载了此策略。
- 生成结果：`story.music_mood`为本次最终成片分类；`story.bgm.match`为实际选曲依据，页面显示“类别→歌曲”、理由、候选数、兜底原因。
- `story-decision.json`保留原验证分类，`story-timeline.json`及最终`story-result.json`保留实际剪点复核后的分类。新旧差异可审计。
- 不把“当前曲库标签”覆盖到老任务的选曲快照。

## 本轮验收与上线边界

测试覆盖五类每类至少两个优先候选、温馨不抽到搞笑/试探专用歌、模型分类异常不拖垮视频、片外与边界丢失证据、原一轮调用数、实际混音参数传递、任务固定选择、老pin兼容、网页标签及理由安全显示。

本轮未额外收费调用视觉或TTS，也没有将人工示例冒称实际AI分类结果。模型真实分类审美还需要后续新视频生成来评估。
