## 代码边界

- `MUKBANG_VISION_CODEX_CLIENT_COMPAT`：服务端显式开关，默认关闭；网页配置接口不能开启。
- 仅绑定本次启动导入的完整 `(base_url, model, api_style)` 与 `codex` 配置来源，要求 Responses；HTTPS 导入也受同样限制。
- 地址 / 路径 / 端口 / 模型 / 接口 / 凭证实际手动更改后停用，改回原值也不自动恢复；完全相同的保存不误关闭。
- `client_identity_headers` 是固定标签白名单，实际请求和 `request_manifest.client_headers` 使用同一函数，不接受任意头字典。
- 配置接口通过 `client_compatibility` 报告生效状态；请求清单不包含 Authorization、密钥或私有信任标记。
- 请求正文、原凭证、拼图完整性检查、总截止时间和单 POST / 无重试逻辑不变。
- 已知官方客户端专用 HTTP 403 改为明确的中文说明；其他 403 保持原行为。错误原文继续脱敏保存。
