# Forehead Captions v2 Implementation Plan

**Goal:** 按用户新反馈，将字幕贴近额头并直接出现/消失，保持一次视觉请求，生成新样片并重启8883服务。

**Architecture:** 同一响应的anchors可附带forehead归一化点；老响应仅有head_box时用头部框上段估计，不追加识图。按采样时间线性插值位置，不再用整句头部框并集的最高点。字幕无淡入淡出、缩放或弹入，音轨原样复制。

**Tech Stack:** 现有Python、pytest和FFmpeg/libass；不新增依赖、不新增视觉模型。

1. 修改tests/test_head_captions.py：额头坐标、时间映射/插值、字框边界、无进出特效、无额外API；先运行确认旧实现失败。
2. 修改mukbang/head_captions.py与定位Prompt，支持forehead点和老框回退，使用居中字幕与按采样位置跟随。只改变排版，不改五句文本、时轴、配音、BGM和原剪辑。
3. 更新输出与服务版本标记为forehead-v2，使用已有一次API返回，另存mi-forehead-caption-v1；检查35秒、700帧、音轨哈希一致，查看每句起止附近画面。
4. 核实8883没有活动任务和准确进程，在本轮用户明确要求重启的授权下执行正常重启；读回版本标记、模型与原提示词库，检查旧任务及新样片可访问。若环境仍明确拒绝，不用其他工具规避该拒绝。
5. 全套回归、更新方法文档并提交推送功能分支；私有素材与凭证不上传。
