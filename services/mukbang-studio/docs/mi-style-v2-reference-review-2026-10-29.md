# 参考复看与文案纠偏：mi-inner-v2

## 用户反馈与原因

用户认为已接通的d7fc4cb2b148文案不可爱、缺少反差、太抽象，句句像有一个逗号把话切成两半，难以代入。该任务的五句确有“这一勺，咪看中了”“这口，得认真尝”等整齐、带姿态却缺少具体反应的措辞。

重新查看用户参考视频的三张既有拼图（覆盖0–58秒），而非相信之前失败的ASR。分析依据可见字幕与动作，不将辅助字幕或视觉音效视为额外说话人；用户已明确全部发声是猫的内心话。

## 重新提炼：之前漏掉的关键

1. **不是每句塑造小威风，而是先有具体反应。** 8秒附近“失算了……”承接前面伸爪/折腾；38秒附近发现侧边开口才有“咦？这有个暗门”。都是眼前变化触发，不是给动作配个态度口号。
2. **反差发生在句与句之间。** 开头威胁、碰壁、重新理解环境、发现出口、出去后自夸构成连贯的判断变化。将它拆成五条各自“小小得意”的金句，会失去前后关系。
3. **错误理解也很具体。** 把笼内结构联想为上床下桌、宿舍、学校，才有后面的不想学习。不能只学“抽象幽默”然后给任何吃饭画面套“本咪拿下”。原梗不移植。
4. **话语长短与语气有变化。** 有极短失落、完整疑问、着急、求助和得意。没有每句“话题＋逗号＋宣言”，也不是固定4–12字。
5. **可爱来自说的和做的有一点落差。** 咪认真相信自己的解释，观众从动作看出另一层；不是额外旁白替观众解释笑点。普通小疑问也是必要的，不强求句句抖包袱。

## 改动与不改动

- 新增prompts/story-mi-style-v2.txt并由正式vision.build_prompts在同一次请求加载，页面显示mi-inner-v2。原v1保留作历史版本。
- 先写当下能脱口而出的具体口语；反差由有证据的前后变化承接；取消创作上的4–12字偏好，但保留原36字/显示时间/留白/片段证据约束。
- 不机械禁逗号，只限制连续重复的两截式宣言。不以删逗号、替换“咪”、加叠词冒充改写。
- performance_direction按自然语义给一句短提示，不统一“前半句停顿后半句得意”。
- 不改音色ID、BGM素材与混音参数、额头样式、吃播P0004、照片规则或近脸互动的选片偏好。不新增语言润色API；新上传仍单次视觉响应后文字TTS。
- 本轮选择正常上传重跑来验证完整自动生成，而非人工替换旧任务台词。独立固定剪点试听更利于严格A/B，但不能单独证明新上传已生效；本轮不额外做两套付费生成。
- 历史/恢复任务按其实际Prompt标记风格，不因当前版本升级而被重标成v2。
