# 小剧场随机BGM Implementation Plan

**Goal:** 下载核验至少10首独立、轻巧俏皮的音乐，为新小剧场本地随机配乐，保留声音、字幕、原声和一次识图流程。

**Architecture:** 官方曲目清单与许可来源入Git，音频与安装清单留本地。正式混音入口按任务目录固定随机曲目并保存署名，后续重复处理复用该曲；旧固定音乐配置兼容。曲库不可用时保留无BGM成片并明确错误，不换成来源不明的参考音乐。

**Tech Stack:** Python / FFmpeg / FastAPI / existing vanilla JS UI。

## 方案取舍

- 采用本地、统一许可的12首初筛曲库：生成时无网络依赖，署名可审计。
- 不采用每次联网搜歌：响应不可控，许可无法逐次保证。
- 不把参考曲变速版本凑成多首：不是不同作品，且原曲许可未确认。
- 官网配器/情绪说明仅用于初筛，不冒称已完成主观听音匹配。

## 可验证步骤

1. `scripts/install_story_music.py`：官方catalog精确匹配12首，保存官方许可证据、下载URL、SHA256；FFmpeg完整解码验证，失败不发布安装清单。
2. `mukbang/story_music_library.py` + `tests/test_story_music_library.py`：校验清单、本地路径和哈希，任务内固定选曲、旧配置兼容，不公开私有路径。先写测试再实现。
3. `mukbang/story_music.py`：正式混音接入选曲、写credits、结果真实曲名与许可；混音参数和视频流不变。
4. `mukbang/server.py`、`web/music.*`、`web/daily.js`：本地试听页、曲名/署名下载，不暴露私有配置；测试路由与旧前端。
5. 对既有无BGM配音中间成片制作独立试听，不覆盖历史任务，不新增视觉/TTS调用；跑pytest及node测试。
6. 核实任务和提示词整理空闲再重启8883。核对API实际启用曲库，提交代码与清单，不提交私人媒体或密钥。

## 版权与边界

候选采用作者官网标注的CC BY 4.0。保留作者、曲名、作品链接、许可证链接与剪辑/混音修改说明，页面提示发布时携带署名。未购买免署名许可，不能称作无条件商用或平台版权匹配免责。原参考曲仍为local_preview_only。
